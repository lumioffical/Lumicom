# LUMICOM — портфолио и три демо-сайта

В корне лежит сайт-портфолио **LUMICOM** (`index.html`, `about.html`, `readyproject.html`, `contact.html`), а в папках — три независимых демонстрационных многостраничных проекта. Каждый сайт: чистый HTML5/CSS3/vanilla JS, без сборщиков и CDN, полностью работает по `file://` (двойной клик по `index.html`) и пригоден для GitHub Pages «как есть».

| Папка | Проект | Тема | Страниц | Особенности |
|---|---|---|---|---|
| `01-veltor-auto/` | **VELTOR AUTO** | автосервис | 6 | тёмный графит + оранжевый, демо-цены в ₽, подробный `service-detail.html` |
| `02-morrow-coffee/` | **MORROW COFFEE** | specialty-кофейня | 6 | светлая молочно-оливковая палитра, фильтр меню без перезагрузки, форма брони столика |
| `03-bytecare-lab/` | **BYTECARE LAB** | ремонт компьютеров | 6 | «лабораторная» навигация, чипы-симптомы → карточки услуг, честные условия гарантии |

## Общие принципы всех трёх проектов

- **Только локальные ресурсы**: шрифты (woff2), изображения (Wikimedia Commons, кредиты — в README каждого проекта) лежат рядом с HTML; `fetch()`, ES-модули и внешние скрипты не используются.
- **Честные формы**: ничего не отправляется на сервер; после валидации показывается локальное сообщение и подсказка позвонить. Валидация имени (≥ 2 символа) и телефона по маске `+7/8 9xx xxx xx xx`.
- **Демо-контент с пометками**: цены, статистика, адреса и телефоны демонстрационные (`ул. Примерная` / `+7 (900) 100-20-30/40/50`), помечены прямо в интерфейсах и README.
- **Адаптив и доступность**: брейпоинты 1200/992(900)/768/560/380, бургер-меню, skip-link, ARIA, `prefers-reduced-motion`, `focus-visible`.
- **Имена изображений описывают содержимое** (`cafe-lounge-copper-lamp.jpg`, `obd-diagnostics.jpg`, `hero-laptop-repair.jpg` и т. п.).

## Связка портфолио ↔ проекты

Секция WORK на `readyproject.html` содержит три карточки, каждая — ссылка на главную страницу соответствующего проекта (`01-veltor-auto/index.html`, `02-morrow-coffee/index.html`, `03-bytecare-lab/index.html`) с обложкой из его папки `images` и двуязычными подписями (EN/RU через `data-i18n`). Остальные страницы портфолио не менялись.

## Анимации

- Все три сайта: reveal-появления при прокрутке, счётчики, hover-эффекты, анимация мобильного меню; везде учтён `prefers-reduced-motion`.
- MORROW COFFEE дополнительно: каскадная анимация карточек при переключении фильтра меню и плавное появление ответов FAQ.
- Портфолио LUMICOM: анимации оригинальные, не менялись; карточки проектов наследуют reveal-каскад страницы, добавлен только focus-стиль ссылки.

## QA

Все три проекта и страницы портфолио проверены автоматикой: статические проверки ссылок/изображений/ресурсов (0 FAIL на всех) + Playwright (Chromium) на 1920/1440/1280/768/430/390/360/320 — ноль ошибок консоли, ноль битых изображений, ноль горизонтального скролла; проверены фильтрация меню (MORROW), бургер-навигация, обе формы бронирования/заявки и переходы из портфолио в каждый проект.
